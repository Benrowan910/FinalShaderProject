# The Project

This is a project that I did for my shader programming and procedural modelling class!

In this project you will find different principals of shader programming and procedural modelling, such as the following

## The Shader
I wanted to make a sort of painted world shader, remaking what's on your screen to look almost like a water color painting. 

Immedietely, I thought of the Kuwahara filter, which is an image smoothing filter that rearranges the pixels on the screen and sort of "rounds them out"
So I decided to make my own Kuwahara style filter to overlay on the game. 

## The Procedural Modelling
I wanted to make a seeded, minecraft style chunk generated world.

In unreal engine, there are plenty of plugins that are community made along with made from epic to utilize to make a chunk style world. 

The plugin I went for was the Auburn Tiny Noise Generator, which I was able to utilize to create fully randomized world in chunk form
The plugin had different kind of noise generation, that would lead to different style of world generation.
